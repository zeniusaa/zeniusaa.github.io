PumpHealth B2W3

Kerja produksi

Halte transferSep 2026 - sekarangIT & Software DeveloperFortasindo

Aplikasi web berlangganan untuk memantau kesehatan pompa sentrifugal di industri, dibuat di PT Performa Integritas Indonesia (Fortasindo). Rumus penilaian yang sebelumnya hidup di spreadsheet Excel engineering saya terjemahkan menjadi engine perhitungan yang teruji, lalu saya bungkus menjadi aplikasi multi-perusahaan dengan hak akses per peran.

Yang saya bangun

  • Health Index dari 5 kelompok parameter: hydraulic, vibration, temperatur/pelumasan/kebisingan, motor listrik, dan kondisi fisik.
  • Modul Design untuk sizing pompa dan membandingkan pompa calon dari vendor.
  • Analisis reliabilitas Weibull: MTTF, shape factor, dan probability plot.
  • Inspeksi berkala dengan foto kondisi, grafik tren, dan import data dari Excel.

Cara kerja

  • Hak akses berbasis peran dan policy, pemisahan data per perusahaan, dan audit log.
  • Dokumentasi teknis: PRD, arsitektur, struktur database, rumus, dan changelog.
  • Menelusuri bug yang hanya muncul di CI Linux (beda huruf besar/kecil pada path) sampai akar masalahnya.

HAMIM API B1

Kerja produksi (magang)

Jun - Agu 20263 bulanBackend Developer InternAcademy Baitul Maqdis

REST API untuk HAMIM, aplikasi hafalan Al-Qur'an bergamifikasi yang dipakai aplikasi Flutter dan dashboard admin web. Setiap ayat dipelajari bertahap: mendengarkan, membaca, lalu kuis menyusun potongan ayat.

Fitur

  • Login email/password, Google OAuth di browser, dan Google Sign-In native untuk Flutter.
  • Satu endpoint mengirim audio, teks Arab, terjemahan, dan soal untuk satu kelompok ayat sekaligus.
  • Sistem nyawa, level, leaderboard, dan akun premium.
  • API admin terpisah untuk dashboard React + TypeScript: kelola pengguna, surah dan ayat, aset, serta analitik.

Keputusan teknis

  • Token admin terpisah dari token pengguna dan tidak bisa saling dipakai.
  • Kuis dinilai di server: urutan opsi diacak dan kunci jawaban tidak pernah dikirim ke client.
  • Idempotency key dan transaksi database agar nyawa tidak terpotong dua kali saat retry atau double-tap.
  • Nyawa dipulihkan dari selisih waktu saat request, tanpa cron job; deploy dengan Docker dan health check.

Prediksi Stres Mahasiswa D1

Tugas besar kelompok

Data MiningTim 3 orangRandom Forest + SMOTE

Memprediksi tingkat stres mahasiswa (Low, Medium, High) selama pembelajaran daring dari aktivitas harian: screen time, durasi tidur, dan aktivitas fisik. Model disajikan sebagai aplikasi Streamlit.

  • Data tidak seimbang ditangani dengan SMOTE, fitur diskalakan dengan StandardScaler.
  • Pengelompokan pola hidup dengan PCA, dan mutual information untuk mencari fitur paling berpengaruh: durasi tidur.
  • Akurasi dilaporkan apa adanya, termasuk validasi silang 5 lipatan.
